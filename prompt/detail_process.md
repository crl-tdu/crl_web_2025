このプロンプトは、卒業論文または修士論文の抽出済みテキスト（`proc/txt/`）から研究室のプロジェクト紹介ページ用の詳細な研究報告書（1500-2000文字）を効率的に生成するためのものです。

## 作業ディレクトリ
- /Users/igarashi/local/crl_web_2025

## 重要原則：正確性確保

### ⚠️ 必須確認事項
1. **論文タイトル**: `proc/txt/{year}_{B/M}_{name}.txt`の冒頭から正確に抽出
2. **研究者名**: ファイル名の`{name}`部分と論文内の氏名表記を照合確認
3. **学位・年度**: ファイル名の`{B/M}`（学部/修士）と`{year}`を正確に反映
4. **英語タイトル**: 論文内の英語タイトルがある場合は併記

### データ基準
- **正解データソース**: `proc/txt/` 以下のテキストファイル（pdftotextで抽出済み）
- **命名規則厳守**: `{year}_{B/M}_{name}.txt` → `{year}_{B/M}_{name}_detail.md`
- **情報の一貫性**: 氏名・タイトル・年度の表記統一

## 使用ツール
- 詳細レポート生成: `claude`
- 品質改善・後処理: `Python`スクリプト（オプション）

## ワークフロー概要

### Phase 1: 情報確認・抽出（必須前処理）
1. **ファイル名解析**: `{year}_{B/M}_{name}.txt`から基本情報抽出
2. **論文冒頭読み込み**: タイトル、氏名、専攻、指導教員を正確に確認
3. **情報整合性チェック**: ファイル名と論文内容の一致確認
4. **キーワード抽出**: 目次、概要、結論から研究領域を特定

### Phase 2: 詳細レポート生成（メイン処理）
1. 抽出済みテキストの構造化解析
2. 研究背景・目的・手法・実験・成果の体系的整理
3. 学術的記述スタイルによる1500-2000文字レポート生成
4. **発表業績の統合**: 論文末尾の発表文献リストを抽出（修士論文のみ）

### Phase 3: 品質保証・後処理（推奨）
1. **情報正確性の最終確認**: 氏名・タイトル・年度の再チェック
2. **学術的表現の統一**: 専門用語、数値表記、引用形式の標準化
3. **文字数・構成の調整**: 1500-2000文字範囲内での最適化

## 前提条件

以下のファイル構造を前提とします：

```
proc/txt/                               ← 【正解データ】抽出済みテキストファイル
└── {year}_{B/M}_{name}.txt            ← pdftotextによる全文テキスト

project/
└── {year}/
    ├── data/
    │   └── projects_{year}.json       ← メタデータ（参照用）
    ├── {year}_{B/M}_{name}_abst.md    ← 概要（参照用）
    └── {year}_{B/M}_{name}_detail.md  ← 【出力】生成する詳細レポート
```

## 処理対象と出力

### 入力（正解データ）
- **テキストファイル**: `proc/txt/{year}_{B/M}_{name}.txt`
  - pdftotextで抽出された論文の全文テキスト
  - 学部論文例: `2019_B_h.emori.txt`
  - 修士論文例: `2019_M_z.meng.txt`

### 出力
- **詳細レポート**: `project/{year}/{year}_{B/M}_{name}_detail.md`

## 詳細レポート生成仕様

### 1. 文字数規定
- **目標文字数**: 1500-2000文字
- **最小文字数**: 1400文字
- **最大文字数**: 2100文字

### 2. 構成要素（必須）

#### ヘッダー部（正確性最重要）
```markdown
# {論文の正確なタイトル}

**研究者**: {正確な氏名} ({学部/修士}, {発表年})  
**キーワード**: {研究領域タグ1}, {技術タグ2}, {応用分野タグ3}, ...

---
```

**ヘッダー作成時の注意事項**:
- タイトル: 論文冒頭の正式タイトルを完全一致で記載
- 氏名: 論文表紙の氏名表記に従う（漢字・カタカナ・アルファベット）
- 学位: B（学部）/M（修士）をファイル名と照合
- 年度: ファイル名の年度と論文内の年度を確認

#### 本文構成（1500-2000文字）
1. **研究背景・動機** (300-400文字)
   - 研究領域の現状と課題
   - 社会的・技術的ニーズ
   - 本研究の位置づけ

2. **研究目的・課題設定** (200-300文字)
   - 解決すべき具体的課題
   - 研究の独創性・新規性
   - 期待される成果

3. **提案手法・システム** (500-700文字)
   - 核心となる技術・アルゴリズム
   - システム構成・実装
   - 従来手法との差異化要素

4. **実験・評価** (300-400文字)
   - 実験設計・条件
   - 評価指標・測定方法
   - 主要な実験結果

5. **成果・貢献** (200-300文字)
   - 定量的・定性的成果
   - 学術的・工学的貢献
   - 今後の発展可能性

6. **発表業績** (リスト形式)
   - 論文末尾の「発表文献」「関連発表」から正確に抽出（修士論文のみ）
   - 著者名、タイトル、発表先、日付を正確に記載

### 3. 記述スタイル

#### 学術的表現
- 客観的・論理的な記述
- 専門用語の適切な使用
- 根拠に基づく論証

#### 可読性配慮
- 段落構成の明確化
- 適度な改行・空白
- 重要事項の強調（**太字**）

#### 技術的精度
- 具体的な数値・性能の記載
- 手法の技術的詳細
- 実験条件の明示

### 4. 品質保証項目

✅ **情報の正確性**: 論文内容との完全整合性確保  
✅ **氏名・タイトルの正確性**: 表記の完全一致確認  
✅ **学術的記述**: 適切な専門用語と論理構成  
✅ **文字数遵守**: 1500-2000文字の範囲内  
✅ **構成の統一**: 5部構成による標準化  
✅ **技術的詳細**: 手法・実験の具体的記述

## トラブルシューティング

### よくある問題と対策

1. **氏名表記の不一致**
   - 症状: ファイル名と論文内の氏名が異なる
   - 対策: 論文内の正式表記を優先、ファイル名は参考として使用

2. **タイトルの不完全抽出**
   - 症状: 改行やフォーマットでタイトルが分割される
   - 対策: 複数行にまたがるタイトルの完全結合

3. **発表業績の抽出ミス**
   - 症状: 参考文献と発表論文を混同
   - 対策: 「本研究に関する発表」セクションの特定

4. **専門用語の誤用**
   - 症状: 研究分野固有の用語を一般化
   - 対策: 論文内の正確な用語をそのまま使用
