このプロンプトは、卒業論文または修士論文の抽出済みテキストから研究室のプロジェクト紹介ページ用の素材（Markdown, JSON）を効率的に生成するためのものです。

## 作業ディレクトリ
- /Users/igarashi/local/2025_crl_www

## 使用ツール
- テキスト処理・素材生成: `claude`
- 品質改善・後処理: `Python`スクリプト（オプション）

## ワークフロー概要

### Phase 1: 基本素材生成（メイン処理）
1. 抽出済みテキストの読み込みと内容解析
2. 概要Markdownの生成（300文字程度）
3. メタデータJSONの作成

### Phase 2: 品質改善・後処理（オプション）
1. **発表業績の統合**: `project/publish.md`から著者の発表論文を自動抽出（修士論文のみ）
2. **文章品質向上**: 引用記号除去、自然な日本語への改善
3. **最終検証**: 品質チェックと統計出力

## 前提条件

以下のファイル構造を前提とします：

```
proc/txt/                               ← 抽出済みテキストファイル
└── {year}_{B/M}_{name}.txt            ← pdftotextによる全文テキスト

project/
├── publish.md                         ← 研究室全体の発表業績データベース（オプション）
└── {year}/
    ├── data/
    │   └── projects_{year}.json       ← 生成するメタデータ
    └── {year}_{B/M}_{name}_abst.md    ← 生成する概要
```

## 処理対象と出力

### 入力
- **テキストファイル**: `proc/txt/{year}_{B/M}_{name}.txt`
  - pdftotextで抽出された論文の全文テキスト
  - 学部論文: `{year}_B_{name}.txt`
  - 修士論文: `{year}_M_{name}.txt`

### 出力
1. **概要ファイル**: `project/{year}/{year}_{B/M}_{name}_abst.md`
2. **メタデータJSON**: `project/{year}/data/projects_{year}.json`

## 出力タスク詳細

### 1. 概要（300文字程度、必須）
高校生にもわかりやすい言葉で研究の背景・目的・意義をMarkdown形式で記述。

**書式：**
```markdown
## タイトル

**研究者情報**：{学部/修士}, 氏名, 発表年  
**タグ**: tag1, tag2, tag3, ...
**概要**：......
```

### 2. タグ抽出（5〜10個、必須）
本研究に関連する技術・分野のキーワードを抽出。以下のうち最低1つを必ず含む：
- 人間センシング
- 人間機械システム
- チームワーク支援
- モーションコントロール
- ロボット間協調

### 3. メタデータJSON（必須）
各論文の基本情報を構造化データとして記録：
```json
{
  "id": "{year}_{B/M}_{name}",
  "title": "論文タイトル",
  "author": "著者名",
  "year": 2024,
  "type": "学部" または "修士",
  "tags": ["タグ1", "タグ2", ...],
  "summary": "一行要約"
}
```

## 実行モード

### 推奨モード: 概要生成
```bash
# 概要とタグのみを効率的に生成（推奨）
claude thesis_process.md "論文テキストファイル" --mode abst
```

### 拡張モード: 詳細生成（オプション）
```bash
# 詳細な研究報告も生成（1200-2000文字）
claude thesis_process.md "論文テキストファイル" --mode detail
```

## 一括処理例

```bash
# 指定年度の全論文を一括処理
cd /Users/igarashi/local/2025_crl_www

# ディレクトリ作成
mkdir -p project/{year}/{data,img,img_all}

# 学部論文・修士論文を一括処理
for f in proc/txt/{year}_*.txt; do
  name=$(basename "$f" .txt)
  echo "Processing: $name"
  claude thesis_process.md "$f" --mode abst > project/{year}/${name}_abst.md
done

echo "処理完了: $(ls project/{year}/*_abst.md | wc -l)本"
```

## 処理のポイント

### 重要な変更点（従来版からの最適化）
- **PDFテキスト抽出は省略**: 既に完了済み（`proc/txt/`）
- **画像処理は不要**: 概要とメタデータ生成に集中
- **概要生成を優先**: 迅速な処理で効率化
- **詳細生成はオプション**: 必要に応じて追加生成

### 処理の簡素化
- テキストファイルから直接Markdown生成
- 画像選定処理を完全に除外
- JSON生成による効率的なデータ管理
- 一括処理スクリプトによる自動化

このワークフローにより、抽出済みテキストから効率的に研究室のプロジェクト紹介ページ用素材を生成できます。処理時間の大幅短縮と安定した品質の素材作成を実現します。
