# ADR-003: Universal Design Color (UDC) Compliance

**Date**: 2026-03-08
**Status**: accepted

## Context

研究室Webサイトのアクセシビリティ基準の選定。WCAG AA準拠を目標とし、カラーパレットの設計方針を決定する必要があった。

## Decision

UDC（ユニバーサルデザインカラー）基準を採用し、色覚多様性に対応したカラーパレットを使用する。WCAG AAのコントラスト比要件（4.5:1以上）を満たす。

## Consequences

### Positive
- 色覚多様性を持つユーザーにもアクセシブル
- 教育機関として適切なアクセシビリティ水準

### Negative
- デザインの自由度が制限される（使用可能な色の組み合わせが限定）
