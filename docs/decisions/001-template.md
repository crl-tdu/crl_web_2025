# ADR-001: Template

**Date**: 2026-03-08
**Status**: accepted

## Context

設計判断の記録（ADR）テンプレート。重要な技術的決定をこのフォーマットで記録する。

## Decision

ADRは `docs/decisions/NNN-kebab-case-title.md` の命名規則で管理する。

## Consequences

### Positive
- 設計判断の背景と理由が追跡可能になる
- 新メンバーのオンボーディングが容易になる

### Negative
- ADR作成の手間が増える（ただし重要な決定のみ記録すればよい）
