# 筋疲労を考慮したアダプティブパワーアシストスーツ

**研究者**: 徐 暢 (学士, 2021)
**キーワード**: パワーアシストスーツ, 筋疲労, 筋電信号, ウェーブレットパケットエントロピー, リハビリテーション

---

## 研究背景・動機

現在、事故や病気で上肢運動障害を患う患者が多数存在し、これらの患者は早期回復を目指して長時間・高負荷の回復訓練を行う場合が多い。しかし、適切な負荷管理を行わない過度な訓練は、筋疲労の蓄積により二次損傷を引き起こす可能性があり、かえって回復を遅らせるマイナス効果をもたらす危険性がある。従来のリハビリテーション用パワーアシストスーツは、一定の抵抗力を患者に与えることで筋肉訓練を行うが、患者の筋疲労状態をリアルタイムで考慮した適応的な負荷調整機能は十分に開発されていない。筋疲労の進行に応じて訓練負荷を動的に調整することができれば、効果的な回復訓練と二次損傷の防止を両立できると考えられる。

## 研究目的・課題設定

本研究の目的は、筋疲労を考慮したアダプティブパワーアシストスーツの開発である。具体的には、筋疲労の変化に応じて目標発揮筋力を動的に調整するシステムを構築し、リハビリテーション訓練中の二次損傷防止を図る。従来の固定負荷による訓練から、生理学的指標に基づく適応的負荷制御への転換を目指す。筋電信号から筋疲労状態をリアルタイムで評価し、ウェーブレットパケットエントロピーを用いた新しい疲労評価手法を提案する。手の開閉運動を対象として、最大発揮筋力（MVC: Maximum Voluntary Contraction）の40%を基準とした負荷調整アルゴリズムの有効性を検証することが主要な課題である。

## 提案手法・システム

本研究では、筋電信号解析に基づく適応的負荷調整システムを提案した。システムの核心は、積分筋電値とウェーブレットパケットエントロピーを組み合わせた筋疲労評価手法である。実験では、まず握力計を用いてMVCを測定し、これを100%MVCと定義した。目標発揮筋力はMVCの40%に設定し、40回の手の開閉運動を実施した。

筋電信号の測定にはMyoWareとArduino UNOを使用し、各運動時の筋電信号をリアルタイムで取得した。信号処理では、ノイズ除去後に積分筋電値を算出し、同時にウェーブレットパケットエントロピーを計算した。これらの値を正規化後、動的負荷調整アルゴリズムに適用した。

負荷調整アルゴリズムは以下の数式で表現される：

**MVC範囲**: MVC = max - min  (式2.1)

**出力目標値変化**: Pout = (max - min)(x - xmean) [kg]  (式2.2)

ここで、xは毎回の運動で算出したエントロピー値、xmeanはエントロピーの平均値、Poutは次回動作の出力変化値である。この数式により、筋疲労状態の変化に応じて目標負荷を動的に調整する機能を実現した。

## 実験・評価

実験は対照実験形式で実施し、目標値調整なしの条件と目標値調整ありの条件で比較評価を行った。実験1では固定目標値で手の開閉運動を実施し、実験2では提案手法による適応的目標値調整を適用した。各実験間には十分な休憩時間を設けて疲労の影響を排除した。

実験結果として、目標値調整を行わない場合は運動回数の増加に伴って筋力が顕著に低下したが、提案手法による目標値調整を適用した場合は筋力の低下が有効的に緩和される結果が得られた。特に、ウェーブレットパケットエントロピーの変化に基づく負荷調整により、筋疲労の進行を抑制しながら適切な訓練負荷を維持できることが確認された。

積分筋電値の変化からも、適応的負荷調整により筋肉への負担が適切にコントロールされていることが示された。この結果は、リアルタイムでの筋疲労評価と負荷調整の有効性を実証するものである。

## 成果・貢献

本研究により、筋疲労を考慮したアダプティブパワーアシストスーツの基礎技術が確立された。第一に、ウェーブレットパケットエントロピーを用いた新しい筋疲労評価手法の有効性を実証した。第二に、筋疲労状態に応じた動的負荷調整アルゴリズムを開発し、その実用性を確認した。第三に、リハビリテーション訓練中の二次損傷防止という重要な医学的課題に対する工学的解決策を提示した。

これらの成果は、上肢運動障害患者のリハビリテーション分野において重要な貢献をなす。従来の一律な負荷設定から、個人の生理状態に適応した個別化医療への発展に寄与する技術である。また、本研究で開発された筋疲労評価手法は、スポーツ科学や労働安全分野での応用も期待される。

将来的には、単一筋肉から複数筋肉の協調動作への拡張、より複雑な動作パターンでの検証、実際の臨床環境での長期評価が課題として残されている。本研究は、人間機械協調システムにおける生体適応技術の新たな方向性を示すものとして評価される。
