# 研究プロジェクト テンプレート作成ガイド

## カード型ポートフォリオ最適化フォーマット

### 新しいテンプレート構造

```markdown
## [研究タイトル]

[学部/修士], [氏名], [年度]年

[タグ1], [タグ2], [タグ3], [タグ4], [タグ5]

[研究の概要を200-300文字で記述]
```

### 従来フォーマットとの比較

| 要素 | 従来 | 最適化版 | 利点 |
|------|------|----------|------|
| タイトル | `## タイトル` | `## タイトル` | 変更なし |
| 研究者情報 | `**研究者情報**：修士, 佐々木元気, 2019年` | `修士, 佐々木元気, 2019年` | 冗長ラベル除去 |
| タグ | `**タグ**: タグ1, タグ2, タグ3` | `タグ1, タグ2, タグ3` | シンプル化 |
| 概要 | `**概要**：研究内容...` | `研究内容...` | 直接的な表現 |

### 例：実際のテンプレート使用例

```markdown
## 協調技能を考慮した力覚フィードバックによる協調作業アシスト

修士, 佐々木元気, 2019年

協調作業, 力覚フィードバック, 人間機械システム, チームワーク支援, 気づかい推定

重い物を二人で持ち運ぶ時や、精密な作業を共同で行う時に必要な「気づかい」を科学的に分析し、より良い協調作業を支援するシステムを開発しました。人間同士の協調作業では、相手の動きを予測したり、負担を分け合ったりする「協調技能」が重要です。本研究では、この「気づかい」の度合いを数値化し、力覚フィードバック技術を使って適切なタイミングで支援を提供する技術を確立しました。
```

### 作成時の注意点

1. **タイトル**: 研究の核心を分かりやすく表現
2. **研究者情報**: `学部/修士, 氏名, 年度年` の順序を厳守
3. **タグ**: カンマ区切りで3-5個、専門用語と一般的な言葉のバランス
4. **概要**: 高校生にも理解できる平易な表現を心がける

### パーサー対応

最新のパーサー `correct_data_sync.py` は両フォーマットに対応：
- ✅ 従来フォーマット（`**ラベル**:` 形式）
- ✅ 最適化フォーマット（ラベルなし）
- ✅ 自動判別・処理

### ファイル配置

- `*_abst.md`: プロジェクト概要（カード表示用）
- `*_detail.md`: プロジェクト詳細（モーダル表示用）
- 両方とも `project/{年度}/` ディレクトリに配置
