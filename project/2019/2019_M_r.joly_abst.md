## Multi Agent Path Planning using Ant Colony Optimisation

**研究者情報**：修士, Joly Raphaël, 2019年  
**タグ**: マルチエージェント経路探索, 蟻コロニー最適化, 経路計画, ロボット間協調, アルゴリズム, 分散システム, 最適化

**概要**：複数のロボットが同じ空間で効率的に移動するための経路計画システムを、蟻の行動を模倣したアルゴリズムで開発しました。蟻がフェロモンを使って最短経路を見つけるように、仮想的なフェロモンを使って複数のロボットが互いに衝突することなく、最も効率的なルートを自動的に発見します。従来の方法では、ロボットの数が増えると計算が複雑になりすぎる問題がありましたが、蟻コロニー最適化により、多数のロボットでも実用的な時間で最適解を見つけることができます。倉庫の自動搬送システム、空港の荷物運搬、災害救助での複数ドローン運用など、多くのロボットが協調する場面での活用が期待されます。
