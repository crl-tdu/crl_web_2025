## Grasping Interface for Virtual Reality Using Wire-Driven Positioning Interface

Poitrimol Bastien (2020年度 修士論文)

[VR技術], [ハプティクス], [ワイヤ駆動], [グラスピングインタフェース], [SPIDAR], [触覚提示], [ケーブル型インタフェース]

VR（仮想現実）空間で物体を自然に掴む感覚を再現するため、ワイヤを使った触覚提示システムの研究です。現在のVRでは視覚情報は豊富ですが、物を掴む時の重さや硬さなどの触覚情報が不足しています。本研究では、複数のワイヤを使って手に力を伝える「SPIDAR」という装置を改良し、VR空間での掴み動作をよりリアルに再現する技術を開発しました。ワイヤの張力を細かく制御することで、様々な材質や重さの物体を掴む感覚を正確に表現できます。VRゲーム、職業訓練、リハビリテーションなど、手を使った精密な作業が必要な分野での活用が期待されます。
