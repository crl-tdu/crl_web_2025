# 第 1 章 緒論スポーツ等あらゆる技術を獲得するために運動学習が行われる．本研究では，投球のような離散的な運動の運動学習を促進をするシステムの開発を進める．本章では，これらの背景とともに本研究での目的を述べる．

1

###### 1.1 背景サッカー，テニス，野球等，多くのスポーツではボールを狙った位置にコントロールする技術が必要とされる．このような技術を含むあらゆる動作の熟達において，運動学習を通して運動制御の精度や効率を向上させることが求められる．

運動学習では， Fig. 1.1 に示すようなフィードバック誤差学習が行われている． [1][2]

人間は，目標軌道と実際の軌道の誤差情報を感覚入力として受け取り、その誤差を修正するように運動指令を生成するフィードバック制御と，予測に基づいて動作指令を生成するフィードフォワード制御を組合せ，正確な動作指令を生成できるように内部モデルの修正を行っている．

例えば，目標位置に正確にボールを投球する運動では，人間は「この速度とこの角度でボールを投げたら目標位置にボールが到達するだろう」と予測をしてボールを投球する．しかし，目標位置と実際のボールの落下位置に誤差が生じた場合，次の投球において人間は，「もう少し速く投げよう．もう少し角度をつけて投げよう．」のように予測の修正を行う．このように目標の動作を実行するための人間の予測が運動学習における内部モデルであり，正確に予測が行えたときが熟達完了である．つまり，人間の内部モデルと操作対象 ( 動作環境 ) のダイナミクスが一致しているときに人間は思い通りに運動や操作が行える．そのため，早期に熟達を完了させるためには，運動学習 ( 内部モデルの修正 ) を促進する必要がある．

###### 1.2 先行研究運動学習を促進することを目的として，姿勢制御の分野において，フィードバックする誤差を増幅させることにより，運動学習が促進されたという報告がある． [3] しかし，

人間が知覚できる不確実な値をフィードバックすると，その誤差を信頼できなくなるため運動学習が進まなくなるといった報告もある． [4][5]

そこで，機械操作 ( 追従運動 ) の運動学習の熟達支援の分野において，人間の気づかないサブリミナルな範囲でフィードバックを変化させるサブリミナルキャリブレーションという手法を用いた研究が存在する．機械特性を大きく変化させると，人間は機械が暴走しているというような感覚を抱き，運動学習が進まなくなる．そこでこの研究では，

サブリミナルな範囲で人間の内部モデルに近づくように機械特性を変化させる手法により，早期に機械特性と人間の内部モデルが近づくことを可能としている．この手法を応用して人間の内部モデルと反対の方向に機械特性をサブリミナルに変化させることにより，人間の運動学習を促進することを可能とした報告もある． [6][7]

しかし，姿勢制御や機械操作のようなフィードバック時間が長く連続的な運動とは違い，フィードバック時間が短くフィードフォワード制御を中心とした投球やダーツのような離散的な運動では，人間が感覚入力として受け取るフィードバックを変化させて運動学習の促進を図る有効的な手法は確認されていない．投球やダーツでコントロール技術の獲得を目指す運動においては，フォームの修正を行い，正確なフォームで運動することでコントロール技術向上を目指す研究が多く報告されている． [8] しかし，冗長的な自由度が運動学習を促進しているという報告もあるため，フォームを固定せず，人間が感覚入力で受け取るフィードバックを変化させることで運動学習を促進できる可能性があると考えられる． [9]

###### 1.4 提案手法本研究では， Vertil Reality(VR) 環境を使用して投球運動を行う．そこで，先行研究のサブリミナルキャリブレーションを応用して， VR 環境の物理パラメータ ( 環境ダイナミクス ) をサブリミナルに変化させることにより，人間への視覚フィードバックを変化させる．

離散的な運動では，追従運動のような連続的な運動とは違い，人間は内部モデルを一定方向に修正を行なっている場面もあるが，目標値に対して，オーバーシュートするように正負どちらにも誤差を発生させ，運動学習が進むにつれてその誤差の振り幅を小さくしている．

そこで，人間の内部モデルの修正量が小さくなることを期待して，環境ダイナミクスの目標値を人間の内部モデルに近づけ，実際の誤差より誤差を減少してフィードバックする手法を提案する．

*g* *h* *, s* *h* と反対の方向に *g, s* を変化させる．前回の投球時と現在の投球時で正解値 *g* *c* *, s* *c* に対して誤差のプラスとマイナスが一致していない場合，すなわち誤差の修正がオーバー

シュートしている場合は，人間の予測した *g* *h* *, s* *h* に近づけるように *g, s* を変化させる．サブリミナルな変化量は人間の予測値 *g* *h* *, s* *h* と正解値 *g* *c* *, s* *c* の誤差に *µ* を乗算した値とした．本実験では *µ* = 0 *.* 5 とした．

また，予備実験のように VR 環境のパラメータが内部モデルよりも正解値から離れないために，そのような場面での *g, s* を以下の式に示すように内部モデルから *±m* 正解値に近づけるか正解値を使用する．本実験では *m* = 1 とした．

*g* ( *n* ) = *g* *h* *± m* *or* *g* ( *n* ) = *g* *c* *,*

(3.3)
*s* ( *n* ) = *s* *h* *± m* *or* *s* ( *n* ) = *s* *c* *,*

20

###### 3.3 実験内容

20 代の男女 17 名がキャリブレーションあり・なしの 2 回の実験を行った．また，それぞれの実験後にキャリブレーションに気づいたかを問うアンケートを実施した．気づいた被験者にはどのくらい確実に気づいたのかを 5 段階の尺度で答えるアンケートも行った．キャリブレーションありの実験でなしの実験より気づいた尺度が大きかった被験者をキャリブレーションに気づいた被験者とした．

以下の式の示すように，それぞれの投球における *y* 方向と *z* 方向の目標値 *y* *goal* *, z* *goal* と落下位置 *y* *real* *, z* *real* の誤差をパフォーマンス指標として取得した．キャリブレーション中は正解値であるパラメータ *g* *c* *, s* *c* を使用した場合の誤差を *y* *real* *, z* *real* として取得した．

*E* *y* = *y* *goal* *−* *y* *real* *,*

(3.4)
*E* *z* = *z* *goal* *−* *z* *real*

# 第 4 章 結論本稿では，離散的な運動の運動学習促進を目的に VR のパラメータを変化させるサブリミナルキャリブレーションの提案を行った．これらについてまとめ，本研究における今後の展望について述べる．

29

###### 4.1 まとめ本研究では，離散的な運動の運動学習を促進することを目的として，人間が感覚入力で受け取るフィードバック誤差をサブリミナルに変化させる手法を提案した．

予備実験においては，環境ダイナミクスの正解値の許容範囲をサブリミナルに変化させる手法を用いて実験を実施した．キャリブレーションによって誤差の減少率は増加したが，有効性は確認できなかった．原因として，誤差が少ない被験者は許容範囲内に内部モデルが位置するため，成功しているフィードバックを受け，運動学習が止まっている可能性があることが挙げられる．そして，内部モデルの修正がオーバーシュートをしている場面のみを想定したキャリブレーション方法であったため，一定方向に内部モデル修正を行なっている場面で対応ができていなかった．

予備実験の課題点を踏まえ，キャリブレーション方法を変更して実験を行った． VR 環境のパラメータの変化量を誤差に応じて変化させることにより，個人差に対応できる手法を用いた．また，内部モデルの修正がオーバーシュートしているときとそうでないときとで，パラメータの変化させる方向を変化させた．全投球の誤差の減少率の比較を行ったところ，キャリブレーションの有無に関わらず，誤差の減少が確認できなかった．そこで目標落下位置ごとに二乗平均誤差を計算し，キャリブレーションのあり・なし両実験において誤差が減少している，すなわち運動学習が進んでいる結果だけを抽出し，比較を行ったところ， z 方向においてサブリミナルキャリブレーションの有効性が確認できた．

30

###### 4.2 今後の展望本研究において，運動学習が進む目標落下位置では，サブリミナルキャリブレーションのによって運動学習が促進されることが示唆された．運動学習が進む実験で，比較を行うことにより，今後サブリミナルキャリブレーションの有効性を確認できる可能性があると考えられる．投球時の人間が入力する初速度や角速度をより正確に計測が可能になることにより， VR 環境内でも現実に近い環境になり，人間の意図が反映されやすくなるため，キャリブレーションの有無に限らず運動学習進むと考えられる．

また，実験結果から，内部モデルの修正がオーバーシュートしている被験者の内部モデルに VR 環境のパラメータが近づけていなかったことから，内部モデルの修正方法の変化によって，キャリブレーション量を変化させることで，さらに運動学習が促進されることも期待できる．
