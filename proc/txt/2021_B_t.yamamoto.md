# 第 1 章 序論近年，リハビリテーションや熟達支援の分野において，機械が人間をサポートするマンマシンインタフェースの発展がめざましいものとなっている．その制御入力として，生体信号と呼ばれる人間が体内から発する生体現象をセンサによって定量化したものが，インタフェー

スを通してデバイス類の制御に活用されている．例を挙げると，心拍，

脳波，脈拍，筋電，発汗などが存在する．その中でも筋電は筋肉を持つ部位を司り，人間の運動意図を正確に反映する最も重要な生体信号のひとつである．筋電を利用したサポートは，主に手や足といった人間にとって重要な部位へのものが多く，四肢欠損者，麻痺者を対象とした研究が盛んに行われている．その具体的なサポート例として有名なものは筋電義手 [1] ，機能的電気刺激 (FES) [2] などが挙げられる．

しかし，筋電をインタフェースへの入力として利用した時に，いくつかの問題点が生じる． 1 つは比較的単純な動きでも作り出すことが難しい，複雑な筋活動のパターン認識である [3]. その原因は， EMG

を取得する際，電極の貼られた周辺一帯の複数の筋活動に関する信号が混ざり合って計測されてしまい，特定が難しくなってしまうためである．また，振幅，周波数のパターンは個人によって変化し，同じ人間でも時間変化で変動することがあり，それもパターン認識の難しさにつながる．もう 1 つの問題は筋電が発生してから実際に張力が発揮されるまでに存在する電気力学的遅延と呼ばれる遅延時間が挙げられる．上肢における遅延時間は約 50ms ほどと言われており，それはデバイス制御への遅延にそのままつながってしまう [4]. このように，筋

1

電位をインタフェースへの入力として利用する際にはいまだに様々な課題・問題点がある．

本研究では，筋電をインタフェースへの入力として利用する際に生じる問題点を解決するための足掛けとして，機械学習の 1 つであるニュー

ラルネットワーク（以下 NN ）用いて，手を動かした際の筋活動のパターン認識を学習させ，その情報から未来の EMG の推定値を予測する「時系列予測」を目的とした．今回使用した NN のモデルは RNN の一種である LSTM である．一般的な順伝搬型 NN は内部に循環を持たず単一方向のみに情報が伝搬するが， LSTM は中間層にループを持ち，

この構造は時間方向につながりを持つデータの処理に有効である．また時系列予測とは，過去の情報を活用して未来の出力の予測値の精度を向上させていくような予測方法のことである．そのため LSTM を用いての学習とは相性が良いことがわかる．時系列データである EMG

の推定値予測の精度が向上し，正確な未来の出力がわかるようになれば，手や足といった筋活動を行う人間の部位の，今までは分からなかった未来の位置情報が取得でき，それによって筋電を利用したデバイス類の持つ課題の解決につながると考えた．

# 第 2 章 筋電発生の機序と生体計測筋電位とは，筋膜表面に生じる筋放電現象を電圧として計測したものであり，筋活動と関係性の強い電気活動である．本章では，筋電が発生する機序，また筋電計測とデジタル制御のための処理・解析について記述していく．

### 2.1 筋の構造と活動の仕組み人体の運動はすべて筋肉の活動の結果であり，筋活動は神経によって支配されている．流れとしては脳からの電気信号が脊髄を通り，特定の筋肉の収縮を促す神経細胞へ辿り着き，筋繊維が張力を発揮する．

### 2.2 筋電計測筋電計測は主に侵襲か非侵襲で大別される．侵襲的計測法の代表例が針筋電図であり，電極を筋組織に刺し入れすることによって，筋から発生する電気信号を近傍で取得することが可能である．この計測方法は主に神経筋疾患診断に利用され，主に医療機関で使用される．それに対して，非侵襲計測法は，通常，表面筋電図のことを指していう．

針筋電計測とは異なり，皮膚表面上に電極を貼付して測定するため，

比較的簡易に利用できる．本研究では表面筋電計測を行った．

**2.2.1** 表面筋電図（ **sEMG** ）の計測原理

sEMG は筋肉の皮膚上に貼付した電極によって， MU から発生する運動単位活動電位（ motor unit action potential:MUAP ）が時間的・空間的に重ね合わされたものを観測したものである． MUAP が同一 MU

から発生する際，ほぼ同じ時刻で支配下の筋繊維上でも観測される．

MUAP が発生した後，腱のある方向へと伝導していく．表面 EMG で実際に観測されるものは，複数の MU からの MUAP 群が重なって伝導してきたものである．観測された EMG の波形情報から，どの MU

から発生した MUAP かを分類する手法を EMG デコンポジションと呼ぶ．この手法は先述のような針電極による侵襲的な測定法にて用いられることが多かった． MUAP 波形の特徴が明確で，雑音も少なく測定できるため， EMG デコンポジションに適しているが，感染症対策や測定対象筋に電極を設置するのに技能を要する．それに対して，表面

EMG は計測が簡便であり，より多くの人が計測を行なうのに都合が良いとされたいるため，近年では表面 EMG での EMG デコンポジションの研究が進められている．

表面 EMG 計測は単極導出法と双極導出法とに分けられる．単極導出法とは， 2 つの電極を用いて 1 つを関電極として対象とする筋上の

8

皮膚に設置し，もう 1 つをその筋以外の位置に不関電極として設置するものである．双極導出法は 3 つの電極を使用し， 2 つの関電極を対象とする筋腹上に筋繊維の走行に沿って 2 ～ 3 cm 離して設置し，他をその筋以外のところに設置する．導出される信号は 0.01 ～ 10 mV と微弱であり，差動増幅器を用いて 60 ～ 80 dB に増幅される．また S/N の改善や動きによるアーチファクトの防止のため，通常は 5 ～ 1000 hz のバンドパスフィルターに通される．先述の通り，表面 EMG は多数の筋繊維の MUAP が時間的・空間的に混在した不規則信号である．生波形から筋の活動様式や運動の制御に関する知見を直接認識するのは容易ではなく，特徴抽出のためのさまざまな処理が必要である．

**2.2.2** サンプリングと量子化

EMG を PC で記録するためには離散化する必要がある．連続するアナログ信号を離散化すると信号の劣化が避けられないので，有意な情報を抽出するためにいくつか注意が必要である． Fig 2.4 に信号の離散化に関するイメージ図を示す．信号 *x* ( *t* ) を離散化すると仮定する．時間 *t* について等間隔に分け，離散化することをサンプリングと呼ぶ．また，縦軸である出力値 *x* ( *t* ) を離散化することを量子化と呼ぶ．各サンプル時間において信号 *x* ( *t* ) に最も近い Fig 2.4 中の点が実際に記録される近似値となる．サンプリング周波数は，サンプリング間隔 ∆ *t* の逆数であり， 1 秒間あたりのサンプル取得数のことである．これを決定するにあたって，サンプリング定理が基準となる．有効な信号情報を抽出するために，信号の有効周波数帯域の上限周波数を *fe* と定義すると，サンプリング周波数 *fs* は， *fs ≥* 2 *fe* を満たす必要があり，この関係のことをサンプリング定理と呼ぶ．一般的には， EMG 信号は最低でも 1 kHz のサンプリング周波数が必要であり，その有効周波数帯域は 5 ～ 500 hz 程とされている． *fe* を 500 Hz としたとき，サンプ

### 2.3 信号処理

**2.3.1** 周波数フィルタリング

EMG 信号を解析する際，雑音を取り除くため周波数フィルタリングによる前処理が必要である． EMG 信号を交流信号とみなし解析を行うため，直流成分近傍の低周波成分を取り除かなければいけない．前述の通り， EMG 信号の有効周波数帯域が 5 Hz から 500 Hz であることから，低域周波数部分をハイパスフィルタを適用し，また，有効周波数帯域の上限の 500 Hz 近傍を遮断周波数とするローパスフィルタも適用する．

**Fig. 3.8.** 忘却ゲートの働き忘却ゲートの出力は次のように与えられる．

*f* *t* = *$\sigma$* ( *W* *f* *·* [ *h* *t−* 1 *, x* *t* ]) (3.44)

26

入力ゲートは新しい入力情報が与えられた際に，どの新しい情報がセル状態にエンコードされるかを制御する．

**Fig. 3.9.** 入力ゲートの働き入力ゲートの出力は，

*tanh* ( *W* *c* *·* [ *h* *t−* 1 *, x* *t* ]) *× $\sigma$* ( *W* *i* *·* [ *h* *t−* 1 *, x* *t* ]) (3.45)

そして 2 つの完全に接続された層の出力の要素ごとの積に等しい．

˜
*c* *t* = *tanh* ( *W* *c* *·* [ *h* *t−* 1 *, x* *t* ]) (3.46)

*i* *t* = *$\sigma$* ( *W* *i* *·* [ *h* *t−* 1 *, x* *t* ]) (3.47)

27

出力ゲートは，セル状態でエンコードされた情報が次のタイムステップの入力としてネットワークに送信されるかどうかを制御する．

**Fig. 3.10.** 出力ゲートの働き出力ゲートの活性化は次のように与えられる．

*o* *t* = *$\sigma$* ( *W* *o* *·* [ *h* *t−* 1 *, x* *t* ]) (3.48)

セルの出力ベクトルは次のように与えられる．

*h* *t* = *o* *t* *× tanh* ( *c* *t* ) (3.49)

長期的な依存関係はセル状態にエンコードされ，勾配が消滅することを防ぐことができる．セル状態は，

*c* *t* = *c* *t−* 1 *× f* *t* + ˜ *c* *t* *× i* *t* (3.50)

のような形式となる．
