# 第 1 章 緒論

従来から世界各地で「ストレス」に対する対策が多く行われてきた．しかしながら，現

代でもストレスはこころの病と言われている通り，ストレスの蓄積による心身の影響が

問題とされている．本研究では，ストレスの影響を軽減するためのアシストについての

開発を進める．本章では以下の項目を述べる．

- 背景

- 先行研究

- 本研究の目的

1

### 1.1 背景

本節では，ストレスが与える現状の問題および解決策について，世界へ与える影響に

ついて述べる．

**1.1.1** 認知負荷へ与える影響

近年，ストレスが認知機能に悪影響を及ぼしていることが問題となっている．認知と

は視覚・聴覚・体性感覚・嗅覚・味覚といった感覚器官を通して，情報を脳が受容する

ことから始まる．これは単純な行動であっても必ず必要とする機能であり，ストレスに

よって支障が起きやすい機能である [1] ．そしてストレスが認知負荷に影響を与えると，

Fig. 1.1 に示すように交通事故の発生に繋がるという問題がある [2] ．このようにストレ

スは運転や運動といった日常でのパフォーマンスに支障を与える危険な因子であるとい

える．

Fig. 1.1: Reason for the accident

2

**1.1.2** **IoT** デバイスの普及

近年， IoT の発達が追い風となっており，人体のバイタルデータを常に収集し，取り

扱うといったことがされている．従来のストレス手法がアンケートといった主観的 ( 心

理学的 ) 評価法が多用されているなか， IoT はストレスモニタリングを担う一角として注

目されている．人体に生体恒常性を乱す刺激 ( ストレッサー ) が加わると，生体恒常性の

維持・回復のために生体反応が生じ，ストレス反応が起こる．このストレス反応によっ

て生体情報や生化学物質の変化が生じるため，これらを計測する様々なストレスモニタ

リング技術の開発が進められていて， IoT にそれを実装することで新たなヘルスケアと

して展開が見込まれる [3] ．

3

### 1.2 先行研究

ストレス状態の解消をするためには，ストレスの測定かつフィードバックについて議論

する必要がある．本節ではストレス測定で使われるバイタルデータについて考えていく．

**1.2.1** 生化学物質によるストレス推定

背景よりストレス反応によって生化学物質の変化が生じるため，これを計測すること

でストレスが計測できる．特に注目されているのが唾液であり，尿や血液と違って非侵襲

的で安易にセンシングすることが可能であり，専門の機器や知識を必要とせずに Fig. 1.2

のような簡易機器で採集することが出来るため，代表的なストレス測定として期待され

ている [4] ．しかし，生化学物質を用いてのストレス計測は生体サンプルを採取する必要

があることから，連続で測定すると日常生活やコンプライアンスに支障をきたす可能性

が高い．そのため，常にヒューマンモニタリングする IoT には不向きであるため，本研

究では利用しないこととする．

Fig. 1.2: Hand-held monitor for sympathetic nervous activity using salivary amylase activity

(reader and test strip; salivary amylase monitor, Nipro Co., Japan).

4

**1.2.2** 生体信号によるストレス推定

ストレス反応は人間の脳波や心拍数においても影響を及ぼすと言われており，これら

を用いてストレスを推定するという試みもある．前述した生化学物質によるストレス推

定と比較して，この手法は測定が連続的に出来て日常生活にも導入出来るものとして，

IoT 分野での活躍が期待される．しかし，生体信号の変化には個人差があること，また

ストレスの種類によって変化する生体信号が異なることによってストレスの種類が推定

出来ないのが問題となっている [3] ．そこで Akmandor らは Fig. 1.3 に示すように，スト

レスと相関性の高い生体信号を取得する多種多用なウェアラブルセンサ (Fig. 1.4) 機械学

習を用いて，個人のストレスをリアルタイムで予測および測定を行い，ストレスコーピ

ングを提示している [5] ．しかし，ストレスコーピングは環境によるものがあることと，

フィードバックが視覚的なものとなってしまい個人の力量によるものとなってしまう．

Fig. 1.3: Stress Detection and Alleviation System

Fig. 1.4: Wearable Sensor

**1.2.3** 音声情報によるストレス推定

前述のセンサを用いてのストレス推定は煩わしいとして，マイクのみによる非侵襲に

計測出来る音声によるストレス推定の開発も進められている [3] ．松尾らはストレスを受

けると発声器官である声帯に関係する筋肉の動きや気道液の年生が影響を受け， Fig. 1.5

のように声帯の挙動に依存する音声のピッチ・レベルが影響を与えていることから，ス

トレス状態らしさの推定を行っている [6] ．この手法の利点として，日常生活や業務野中

で対象者に意識させることなく計測することができることである．特に迷惑電話を受け

た際や顧客とのトラブルを受けた際にいち早くストレス状態を検出できるため，企業の

生産性を上げる技術として注目されている．しかし，本研究では発音するというタスク

ではなく，運転中のパフォーマンスとの結びつきを検討するため，この手法は利用しな

いこととする．

Fig. 1.5: Relation between Power Spectrum and Stress Situation

### 1.3 本研究の目的

本研究では，従来のストレスのリアルタイム推定とドライビングのパフォーマンスと

の相関性について考えることで，ストレスによる影響を軽減するアシスタンスへの検討

が出来ると考える．それを実現するために，まず始めにストレスのリアルタイム測定の

手法を確立させる．ストレスの測定手法は脳波や心電図といった生体信号を用いること

で測定することが出来るが， Fig. 1.4 のように大量のセンサを着けると逆に肉体的・精神

的負荷がかかってしまうため，少量のセンサでの実験を行う．

### **2.3 GSR**

GSR(Galvanic Skin Response) とは皮膚の電気伝導度を測定する手法で，不安などの

精神的な影響を受けたとき，汗腺による発汗が起きやすくなると言われている [11] ．こ

の GSR を測定する場合は手首や指先に電極を装着し，電気抵抗の値を測定する．測定

値は測定部位が発汗することで皮膚上の電気抵抗が減って流れる電流量が増加する．

# 第 4 章 結論

本稿ではストレスの推定と遅延時間というストレッサーからどのように反応を引き起

こしパフォーマンスに影響するかについて調べる．これらについてまとめ，本研究にお

- まとめ

- 今後の展望

39

### 4.1 まとめ

本研究ではまず LF/HF および GSR を用いてストレスレベルに応じてどのようにス

トレス評価が変動するかについて確認をした．そのために最初は ECG は適切な処理を

施すシステムを構築し，適切に Peak を摘出することに成功した．次にそれの間隔を高

速フーリエ解析をし， LF/HF 成分を算出し，リアルタイムで LF/HF を見るための逐次

算出を行った．結果としては LF/HF においてはストレスレベルに応じてストレスが変

動することが確認できた．しかし，ストレスレベル低と高の差はそれほどなかったため，

改めて結果の信憑性について検討していく必要がある．また，リラックス状態について

も改めて環境を変えての測定をしたい． GSR に関しては，ドライビングタスク中の揺ら

ぎを確認することが出来たが，ストレスレベルで変動することが確認することが出来な

かった．そのため，これがノイズの影響か確認するためのハンドリング時の GSR デー

タを省いたりすることで，改めて検討したい．

40

### 4.2 今後の展望

本稿では， LF/HF を用いた時系列解析からパフォーマンスとの結びつきを検討すると

いうものだったが， LF/HF だとストレス反応を受けてからの遅延が生じるため，リアル

タイムでのアシストは困難だと考えられる．そのため，予めこれを考慮に入れたうえで

のストレス・コーピングが大切であるといえる．次に操作パフォーマンスについてだが，

今回はリアルタイムでの解析手法の実験として遅延時間というストレッサーがもろに操

作パフォーマンスに影響を受けてしまう実験をしたため，次は認知的にかかるストレッ

サー ( 例えば信号や通行者を増加させる ) を変えてどれほど運転に影響が出るかといった

方面も考えていきたい．
