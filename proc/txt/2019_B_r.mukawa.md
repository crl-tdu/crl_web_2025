# 第 1 章 緒論本稿では三次元空間上での使用と，注視点のみではなくその周囲の情報すなわち周辺視野を考慮した注意推定システム「 Attention Grid 」

を開発し，人間の視線情報の計測を行い注視点および注意推定を行う．

本章では，以下の項目を述べる．

1

### 1.1 背景近年，案内ロボットや介護ロボットなど人間社会に深く関わる知能ロボットの開発が盛んに行われており，その実用化が多くの業界から期待されている [1] ．

Fig. 1.1: Information processing amount by five senses

ロボットが人間社会に違和感なく溶け込むには，人間との円滑なコミュニケーションが必要不可欠である．人間は無意識に相手の意図や注意を読み取り，そこから行動や思考を予測し，それを阻害しないように活動する「協調」を行っている．そして人間は自身の行動や思考を阻害されるとストレスを感じるという報告がある [2] ．したがってロボットが今後の人間社会に深く関わっていくには，人間と同様に意図や注意を読み取り行動する「協調」を行う必要がある．現在ロボットが人間の動きや存在を検出し，その情報を元に自身の動作を決定する技術は存在している．しかし人間の動きだけでは，意図や注意を読み取るのは困難である．

2

先行研究として人間の意図や注意は視覚に現れるとの報告がある [3] ．

そのため視覚情報の大半を占める視線情報を用いることで，人間の意図や注意を読み取ることが期待できる．人間の視覚的注意は，注視点以外に周辺視野から情報を取得しており，ロボットに搭載することを想定すると，三次元空間に対応した注意推定技術が求められる．しかし現在の技術では周辺視野を考慮した，かつ三次元空間に対応した注意推定技術は実現されていない．

3

### 1.2 先行研究視線は人間の心理状態を推測する情報として用いることが可能であることから，視線計測に関する研究は多く行われている．本節では先行研究として提案されている視線計測技術および注意推定技術の概要と研究状況について述べる．

*•* 視線停留計測 [4]

*•*Attention Map [5]

4

**1.2.1** 視線停留計測人間の好み，興味等の感情は外部からの測定が難しく，定量的評価が非常に困難な状況である．人間は視覚から情報を得て思考しており，

興味，好意がある対象に対して特徴があるといわれている．そこで田中らは人間の視線情報を解析し，停留，サッケードの有無等から人間の好みの判別を行う研究を行った．結果として視線情報と好みに相関があることが確認された．しかし，これは注視点のみを考慮した計測である．人間の注意は注視点のみではなく，その周囲の情報すなわち周辺視野を有するものである．そのため人間の注意分布を計測し，その情報を用いることを想定した場合，この手法では情報が不足してしまう問題が挙げられる．

5

**1.2.2** **Attention Map**

Attention Map は石原らの提唱する視覚的注意を計測する手法である．人間の視覚的注意は点ではなく一様でない分布であると考えられるため，注意の分布，即ち注視点の周囲を考慮した注意の推定が必要になる．そこで石原らは，人間の注視点の周囲の情報を考慮した注意推定手法 Attention Index を提唱し， Attention Index をマップ化したものを Attention Map と略称した．実験として間違い探しタスクを構築し注視点のみの測定と比較したところ， Attention Index を用いた時に妥当な数値，即ち被験者に気づかれにくいという結果が得られた．

したがって Attention Index の有意性が示唆された．しかし，石原らの実験環境は二次元平面に限ったものであった．そのため，ロボットの適応には奥行きを考慮した，すなわち三次元空間での注意推定システムが必要と考えられる．

6

### 1.3 目的本研究では，人間とロボットの円滑なコミュニケーションを支える技術の実現を試みる．注視点以外に周辺視野から情報を取得，かつ三次元空間に対応した注意推定技術を実現することで，ロボットの協調性が向上し，人間とロボットがより快適な関係を築くことが期待できる．そのため，本研究では注意推定システム「 Attention Index 」を三次元空間に拡張する「 Attention Grid 」の提案を行う．またその有用性を実験的に検証する．

7

### 4.1 実験内容人間は情報を得ようとする箇所に強い注意を向けるため，人間が強く注意している箇所の Attention Index の値が大きいことが確認できれば，

### 4.3 考察注視点の精度すなわち信頼性は，視線がねじれの位置で交差した時の二点間の距離を求めることで検証した．その際二点間の距離が 0.1[m]

以上離れている場合は，算出した注視点座標の信頼性が低いと定義する．実験中の二点間の距離を Fig. 4.5 に示す．

### 5.2 今後の展望今後の展望として次のことが挙げられる．

*•* Attention Grid

本研究では奥行きを考慮した三次元空間上での注視点を計測することを可能とした．しかしながら，エージェントの移動を X 軸,Y 軸固定とした注視点の算出を確認したのみであり，また得られた注視座標を用いて三次元上での注意推定の可能性を確認するまでには至らなかった．そのため，注視点を算出するアルゴリズムの修正及び，注意を 3D

マッピングするプログラムの作成等が課題として挙げられる．

*•* Attention Grid の応用奥行きを考慮した注視点算出及び注意推定は人間が他者や物を見てる見ていないという判別に加え，それらを見ている際手前を注意して見ているか，奥を注意して見ているかの判別が可能となる．この仕様を Attention Grid と組み合わせることで，興味があるときはより情報を探ろうと対象物の奥を注意して見ていたり，逆に興味がないときは対象物の手前を注意して見ているといった検証が可能となる．したがって，人間の好き嫌いの感情を科学的に評価，すなわち注意と好みの相関性の検証が応用例として挙げられる．

*•* 実空間での応用今後の展望として Attention Grid が完成した後，ヒューマノイドロボットへの搭載を行い，実空間での実用化の検証を行う．更に高レベルの気づかいができる介護ロボットや案内ロボット， Attention Grid

を用いて人間の注意を読み取った動作を行うマジシャンロボットの実現へ繋げていきたい．
