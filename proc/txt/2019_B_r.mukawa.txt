第 1 章 緒論
本稿では三次元空間上での使用と，注視点のみではなくその周囲の
情報すなわち周辺視野を考慮した注意推定システム「Attention Grid」
を開発し，人間の視線情報の計測を行い注視点および注意推定を行う．
本章では，以下の項目を述べる．

• 背景
• 先行研究
• 目的

1

1.1

背景

近年，案内ロボットや介護ロボットなど人間社会に深く関わる知能
ロボットの開発が盛んに行われており，その実用化が多くの業界から
期待されている [1]．

Fig. 1.1: Information processing amount by ﬁve senses

ロボットが人間社会に違和感なく溶け込むには，人間との円滑なコミュ
ニケーションが必要不可欠である．人間は無意識に相手の意図や注意
を読み取り，そこから行動や思考を予測し，それを阻害しないように
活動する「協調」を行っている．そして人間は自身の行動や思考を阻
害されるとストレスを感じるという報告がある [2]．したがってロボッ
トが今後の人間社会に深く関わっていくには，人間と同様に意図や注
意を読み取り行動する「協調」を行う必要がある．現在ロボットが人
間の動きや存在を検出し，その情報を元に自身の動作を決定する技術
は存在している．しかし人間の動きだけでは，意図や注意を読み取る
のは困難である．
2

先行研究として人間の意図や注意は視覚に現れるとの報告がある [3]．
そのため視覚情報の大半を占める視線情報を用いることで，人間の意
図や注意を読み取ることが期待できる．人間の視覚的注意は，注視点
以外に周辺視野から情報を取得しており，ロボットに搭載することを
想定すると，三次元空間に対応した注意推定技術が求められる．しか
し現在の技術では周辺視野を考慮した，かつ三次元空間に対応した注
意推定技術は実現されていない．

3

1.2

先行研究

視線は人間の心理状態を推測する情報として用いることが可能であ
ることから，視線計測に関する研究は多く行われている．本節では先
行研究として提案されている視線計測技術および注意推定技術の概要
と研究状況について述べる．

• 視線停留計測 [4]
• Attention Map [5]

4

1.2.1

視線停留計測

人間の好み，興味等の感情は外部からの測定が難しく，定量的評価
が非常に困難な状況である．人間は視覚から情報を得て思考しており，
興味，好意がある対象に対して特徴があるといわれている．そこで田
中らは人間の視線情報を解析し，停留，サッケードの有無等から人間
の好みの判別を行う研究を行った．結果として視線情報と好みに相関
があることが確認された．しかし，これは注視点のみを考慮した計測
である．人間の注意は注視点のみではなく，その周囲の情報すなわち
周辺視野を有するものである．そのため人間の注意分布を計測し，そ
の情報を用いることを想定した場合，この手法では情報が不足してし
まう問題が挙げられる．

5

1.2.2

Attention Map

Attention Map は石原らの提唱する視覚的注意を計測する手法であ
る．人間の視覚的注意は点ではなく一様でない分布であると考えられ
るため，注意の分布，即ち注視点の周囲を考慮した注意の推定が必要
になる．そこで石原らは，人間の注視点の周囲の情報を考慮した注意
推定手法 Attention Index を提唱し，Attention Index をマップ化した
ものを Attention Map と略称した．実験として間違い探しタスクを構
築し注視点のみの測定と比較したところ，Attention Index を用いた時
に妥当な数値，即ち被験者に気づかれにくいという結果が得られた．
したがって Attention Index の有意性が示唆された．しかし，石原らの
実験環境は二次元平面に限ったものであった．そのため，ロボットの
適応には奥行きを考慮した，すなわち三次元空間での注意推定システ
ムが必要と考えられる．

6

1.3

目的

本研究では，人間とロボットの円滑なコミュニケーションを支える
技術の実現を試みる．注視点以外に周辺視野から情報を取得，かつ三
次元空間に対応した注意推定技術を実現することで，ロボットの協調
性が向上し，人間とロボットがより快適な関係を築くことが期待でき
る．そのため，本研究では注意推定システム「Attention Index」を三
次元空間に拡張する「Attention Grid」の提案を行う．またその有用
性を実験的に検証する．

4.1

実験内容

人間は情報を得ようとする箇所に強い注意を向けるため，人間が強く
注意している箇所の Attention Index の値が大きいことが確認できれば，
その妥当性を検証することができると考えられる．そのため Attention

Index 値の高い箇所と人間の注意の関連性の確認のための測定実験を
行う．Unity を用いて仮想空間に Fig. 4.1 に示すような実験タスクを
構築し実験を行う．幅 1.5[m] の道路に沿って人型エージェントが被験
者に対して 5[m] から 1[m] の距離を歩行するよう設定し，被験者には
エージェントの顔を注視するよう指示を行った．
実験手順として被験者が実験中エージェントの顔以外を注視しない
よう，まず実験タスクに慣れさせる時間を取った．慣れたところで実
験を開始し，被験者の注視点の軌跡を記録し Attention Index を計算
する．その後 Attention Index を 3D マッピングした Attention Grid を
作成し，エージェントの軌跡と比較する．また同時に被験者の注視点
の精度（信頼性）を計測する．実際の実験風景を Fig. 4.2，実験タス
クの様子を Fig. 4.3 に示す．

4.3

考察

注視点の精度すなわち信頼性は，視線がねじれの位置で交差した時の
二点間の距離を求めることで検証した．その際二点間の距離が 0.1[m]
以上離れている場合は，算出した注視点座標の信頼性が低いと定義す
る．実験中の二点間の距離を Fig. 4.5 に示す．

Fig. 4.4 より，移動するエージェントを追従するように注視点の変
化が確認できた．しかし 35[s] より前の注視点座標とエージェントの移
動ログを比較すると追従できていない箇所があった．この原因として
二点間の距離が離れていることが挙げられ，Fig. 4.5 より追従できて
いない時間帯の二点間の距離は 0.1[m] より離れており，追従できてい
ない箇所の注視点の信頼性が低いことが分かる．
この解決案として FOVE 0 のファームウェアやソフトウェアのアッ
プデート，また FOVE 0 以上に詳細な視線情報を取得できるヘッドマ
ウントディスプレイを採用することで改善が期待できる．

5.1

まとめ

本研究では，人間とロボットの円滑なコミュニケーションを支える技
術の実現のため，Attention Index を三次元空間で計測する Attention

Grid を提案した．FOVE 0 を用いて視線情報を計測し，その値を元に
アルゴリズムを作成，その後奥行きを考慮した実験を行い，結果とし
て仮想空間上での注視点の算出が示唆された．今回の実験では 20 代の
男性と女性を対象とした測定実験であったため，年齢の違いが及ぼす
結果への影響を確認することができなかったため，今後の検討課題に
挙げられる．また今回の実験では三次元空間上での注視点算出に限っ
たものだったので，得られた注視点を用いて注意推定を行う必要も挙
げられる．

28

5.2

今後の展望

今後の展望として次のことが挙げられる．

• Attention Grid
本研究では奥行きを考慮した三次元空間上での注視点を計測するこ
とを可能とした．しかしながら，エージェントの移動を X 軸,Y 軸固定
とした注視点の算出を確認したのみであり，また得られた注視座標を
用いて三次元上での注意推定の可能性を確認するまでには至らなかっ
た．そのため，注視点を算出するアルゴリズムの修正及び，注意を 3D
マッピングするプログラムの作成等が課題として挙げられる．

• Attention Grid の応用
奥行きを考慮した注視点算出及び注意推定は人間が他者や物を見て
る見ていないという判別に加え，それらを見ている際手前を注意して
見ているか，奥を注意して見ているかの判別が可能となる．この仕様
を Attention Grid と組み合わせることで，興味があるときはより情報
を探ろうと対象物の奥を注意して見ていたり，逆に興味がないときは
対象物の手前を注意して見ているといった検証が可能となる．したがっ
て，人間の好き嫌いの感情を科学的に評価，すなわち注意と好みの相
関性の検証が応用例として挙げられる．

• 実空間での応用
今後の展望として Attention Grid が完成した後，ヒューマノイドロ
ボットへの搭載を行い，実空間での実用化の検証を行う．更に高レベ
ルの気づかいができる介護ロボットや案内ロボット，Attention Grid
を用いて人間の注意を読み取った動作を行うマジシャンロボットの実
現へ繋げていきたい．
