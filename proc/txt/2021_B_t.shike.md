# 第 1 章 序論本研究では，自律神経解析によって得られた HF(High Frequency) の比較によって覚醒状態の評価を可能とし，快・不快を用いた温度提示により覚醒状態の促進の検討を行う．本章では，以下の項目について述べる．

1

### 1.1 背景現在，自動車による交通事故は年々減少している．しかし，安全不確認，脇見運転，漫然運転などのヒューマンエラーによる交通事故はそれほど減少していない．継続的に交通事故を減らすためには，漫然運転の原因となる疲れや居眠りなど運転者の覚醒状態を把握していくことや覚醒の低下を防止することが有効であると考えられている [1] ．

また，自動化された運転環境下における運転者の覚醒状態の低下が懸念されている．自動運転の運転支援レベルはシステムの機能に応じて

～レベル 0 5 の段階でクラス分けされている．一般的に自動運転と呼ばれるシステムはレベル 2 以上であるが，レベル 2 ， 3 の段階では運転者による周辺環境監視や緊急時の対応が必要であるため，運転者の覚醒が低下することを避けなければならない [2] ．

2

### 1.2 関連研究

**1.2.1** 覚醒状態の評価覚醒状態を推定する方法として人間の生理状態から推定する方法 ( 心拍, 脳波, 目の動きなど ) ，車両情報から推定する方法 ( 車両の横揺れや白線逸脱を検知など ) の 2 種類がある．後者は，車両情報から間接的に覚醒状態を推定するため，必ずしも運転者による直接的原因ではない [1] ．前者である人間の生理状態から推定する方法で覚醒状態の推定を行う．その中で覚醒状態と関係がある心拍のゆらぎを用いて自律神経の解析を行い覚醒状態を推定する．自律神経を解析する方法と

～して， LF(Low Frequency : 0.04 0.15Hz)/HF(High Frequency : 0.15

～0.4Hz ) というものがある．活動的な場合は HF 成分が低く，リラックスしている場合は HF 成分が高くなる．また，覚醒状態のとき LF

成分より HF 成分に強い傾向が見られるため HF の増減に着目して推定を行う [1] ．

3

**1.2.2** 温熱的感覚温度に関係した感覚 ( 温熱的感覚 ) には温度感覚と温熱的快・不快感の 2 種類がある．温度感覚は「熱い，冷たい」といった温度を表現するもので，温熱的快・不快感とは「暑い，寒い」といったその温度が快適か不快であるか表されるものであり，皮膚温度刺激や温度条件に依存する感覚である [3] ．これらは暑さを感じているときは冷却刺激は快適，加熱刺激は不快を感じ，寒さを感じているときは加熱刺激は快適，冷却刺激は不快に感じる．また，温度や湿度は温熱的感覚に影響を与えるだけでなく，健康や覚醒度に影響を与える [4] ．

4

### 1.3 目的本実験では，自律神経解析によって得られた HF の増減値によって覚醒状態の評価を行い，快・不快による温度提示を用いて覚醒状態の促進を行う．

### 5.1 結論本研究では，漫然運転によるヒューマンエラー事故，自動化された運転環境下における覚醒状態の低下の懸念から快・不快による温度提示によって覚醒状態の促進の検証を行った． Table. 1,Table.2 から冷却

( 快・不快 ) ，加熱 ( 不快 ) は覚醒状態を促進に有効であることが確認できた．また，加熱 ( 快適 ) の場合は覚醒状態が低下した．これは，加熱が心地良い温度帯であるため眠気を催してしまったと考えられる．しかし，被験者が少ないため人によっては加熱 ( 快適 ) が覚醒状態を促進する可能性があると考えられる．さらに，快適な温度で覚醒状態を促進することは少ないストレスで覚醒状態を低下を防止することができると考えられる．

26

### 5.2 今後の展望はじめに，現状の課題としては被験者が 1 人であるため有意性に欠けると考えられる．そのため今後は，被験者を増やすことでデータを多く取得し，有意性や個人差を検討をしていく必要がある．次に，覚醒状態が促進されたことによって運転の操作性パフォーマンスが上達しているのかドライブシュミレータを用いて検討していく必要がある．

最後に，本研究では運転中における覚醒状態の促進の検討を行ったが運転中以外においても不眠症の改善，作業時の集中力の向上，運動パフォーマンスの向上に繋がると考えられる．
